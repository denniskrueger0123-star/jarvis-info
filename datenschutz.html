Datenschutzerklärung für Jarvis

Jarvis ist ein privater Sprachassistent für genau einen Nutzer, seinen Entwickler. Er läuft ausschließlich auf dessen eigenem Rechner.

Welche Daten Jarvis nutzt

Über die Google Tasks API liest Jarvis die Aufgabenlisten und Aufgaben des eigenen Google-Kontos, legt Aufgaben an und hakt sie auf ausdrücklichen Wunsch ab. Andere Google-Daten werden über diese Anwendung nicht abgerufen.

Speicherung und Weitergabe

Der Zugangsschlüssel liegt nur lokal auf dem Rechner des Nutzers. Aufgaben werden nicht dauerhaft gespeichert und nicht an Dritte verkauft oder weitergegeben. Zum Formulieren gesprochener Antworten kann der Text einer Aufgabe an einen KI-Dienst übermittelt werden, den der Nutzer selbst beauftragt hat.

Widerruf

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung.
